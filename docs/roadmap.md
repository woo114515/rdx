# 开发路线图

## 阶段 0：需求与安全边界

- [x] 确认 RDK X5、MS200P、IMX219、麦克纳姆底盘和固定叉形结构
- [x] 确认三个 Demo 独立验收，优先使用 Python
- [x] 确认开发顺序和公开仓库协作方式
- [ ] 确认现场急停与演示启动方式

## 阶段 1：实机接入

- [x] 建立 SSH 密钥接入并运行只读检查
- [x] 记录系统、ROS、厂商工作区、串口和设备权限
- [ ] 清理或扩容根分区，为构建和录包预留空间
- [ ] 分别验证底盘、雷达、相机、里程计、IMU 与 TF
- [ ] 验证安全停车、命令超时和速度限制

## 阶段 2：8 字基本控制

- [ ] 建立可配置轨迹与低速控制节点
- [ ] 在架空车轮和清空场地两种条件下验证
- [ ] 提供独立启动命令和 Demo 检查表

## 阶段 3：SLAM 与导航

- [ ] 遥控采图并保存/加载二维地图
- [ ] 完成地图定位、目标规划和自主行驶
- [ ] 验证突然出现障碍物时的减速、停车与恢复

## 阶段 4：柱体分类推动

- [ ] 标定 IMX219 及雷达/相机/叉形结构外参
- [ ] 检测柱体并区分暖色与冷色
- [ ] 完成自主搜索、目标选择、对准和推动状态机
- [ ] 将两类柱体整理为两堆并提供独立 Demo

## 待确定参数

- 动态障碍物安全距离和持续阻塞策略
- 柱体具体颜色、数量、外观和初始分布
- 冷暖色分类方法，以及是否采用模型推理
- 两堆的选址、聚集尺度和柱体直立要求
- 场地尺寸、边界、光照、固定障碍物及验收时间

这些项目不得在算法中写死。先提供保守默认值和 YAML 参数，获得现场规则后再固化 Demo 配置。
