## 待确定参数

- 动态障碍物最终安全距离和持续阻塞等待时间
- 柱体具体颜色、数量、外观和初始分布
- 冷暖色分类方法，以及是否采用模型推理
- 两堆的选址、聚集尺度和柱体直立要求
- 场地尺寸、边界、光照、固定障碍物及验收时间

这些项目不得在算法中写死。先提供保守默认值和 YAML 参数，获得现场规则后再固化 Demo 配置。
