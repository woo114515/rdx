## 采用参数

```yaml
blue:  {lower: [88, 180, 60],  upper: [100, 255, 255]}
green: {lower: [40, 22, 70],   upper: [80, 90, 230]}
pink:  {lower: [155, 100, 60], upper: [175, 230, 240]}
```

粉色现场样本集中在 H=160–169，因此使用一个连续区间，不再保留未经数据支持的
H=0 附近占位区间。
